## 修复 · 当天补记（评估功能报错）

- **问题**：点击「评估今晚」报 `Cannot read properties of undefined (reading 'sunset_astronomical')`。
- **根因**：原代码依赖 `api.open-meteo.com/v1/astronomy` 端点获取天文黑夜时刻与月相，但该端点已返回 404 Not Found；且 Forecast API 也不支持 `sunrise_astronomical` 这个 daily 变量。外部天文数据源失效，导致 `j.daily` 为 `undefined`。
- **修复**：移除对外部天文接口的依赖，在 `index.html` 内联 **SunCalc 1.9.0（MIT）** 算法库，改为**本地实时计算**天文黑夜窗口（太阳高度角 −18° 的 `night`/`nightEnd`）与月相（照亮比例 + 月相名）。现在整个工具仅保留一个 Open-Meteo 天气请求，天文部分完全离线、永不再因外部服务波动而失败。
- **验证**：SunCalc 本地计算结果正确（北京 9/16 天文夜 19:57→次日 04:24，月相蛾眉月 26% 照亮）；天气接口纯 hourly 请求实测返回 48 小时数据点正常；内联脚本语法校验通过。
- **改动文件**：`index.html`（核心逻辑）、`README.md`（数据来源说明）。

- **21:15 功能新增**：新增「📍 定位我的位置」按钮，点击调用 `navigator.geolocation.getCurrentPosition` 自动填入用户当前经纬度与地点名。已处理权限拒绝/定位失败/超时三种错误并给出中文提示；附注定位需在 https 或 localhost 下使用（file:// 受限）。语法校验通过。
