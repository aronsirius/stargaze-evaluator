# ✦ 观星适宜度评估器（Stargaze Suitability Evaluator）

由 **天狼星**（AI 助手）为账号主人 **Sirius**（业余天文 / 星空摄影爱好者）打造的一个小工具：
输入一个地点的**经纬度**，它综合多项天文与气象因素，告诉你**今晚适不适合拍星**，并给出评分、分级和针对性提示。

> 纯前端静态网页，**双击 `index.html` 即可使用**，无需安装、无需密钥。
> 天气数据来自 [Open-Meteo](https://open-meteo.com) 免费接口（无需密钥）；**天文黑夜窗口与月相由内置的 SunCalc 算法在本地实时计算，完全离线、不依赖任何外部天文接口**，因此即使天文数据服务不可用也不会影响评估。

---

## 怎么用

1. 打开 `index.html`。
2. 填**纬度 / 经度**（默认是北京附近，可改成你常去的拍摄地）。
3. 不会查光污染就先留 Bortle=4；知道视宁度就拉一下滑块，不知道留 0。
4. 点「评估今晚」——立刻出结果。
5. 觉得这地点常去，填个名字点「＋保存当前地点」，以后点一下芯片就能直接算。

---

## 评分逻辑

总分 = 各因素 0–100 分按权重加权。

| 因素 | 权重 | 含义 |
|------|------|------|
| 云量 | 45% | 越低越好 |
| 降水概率 | 15% | 越低越好 |
| 湿度 | 15% | ≤60% 最佳（高湿易结露） |
| 风速 | 10% | ≤10km/h 最佳（防风抖） |
| 月光干扰 | 10% | 按「拍银河」标准，满月会压暗银河 |
| 光污染 Bortle | 5% | 1 最黑 → 9 最亮 |
| 视宁度（可选） | 10% | 填入时启用，从云量权重里分 10% 给它 |

分级：**≥75 非常适合 · 60–74 适合 · 45–59 一般 · <45 不适合**。

## 已知限制 / 后续可加

- **光污染**目前靠手动填 Bortle；以后可接免费光污染图层自动查询。
- **视宁度**免费实时数据少，暂为可选项；可接气象模型近似。
- 现在评估的是「今晚」整夜窗口（太阳高度角降到 −18° 的天文夜开始 → 次日升回 −18° 的天文夜结束），由本地 SunCalc 计算。
